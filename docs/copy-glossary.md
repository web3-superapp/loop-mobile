# 用户可见文案词表

适用范围：`lib/` 里任何会渲染到屏幕上的字符串 —— 标题、副标题、空态、不可用态、
错误提示、按钮、Toast、`LoopNotice` 正文、`Semantics` 标签。

不适用：注释、日志（`debugPrint` / `developer.log` / `assert`）、`test/`、`docs/`、
`reasonCode` 常量定义本身、`lib/integrations/backend/v2/` 传输层的 wire 常量。

守卫：`scripts/check_harness.py` 的 `check_user_visible_copy`，用例在
`tests/test_check_harness.py`。

### 1.2 不要写（守卫不拦，评审拦）

| 内部说法 | 用户说法 |
| --- | --- |
| 服务端 / 后端 / 客户端 | 省略；确实要指代产品时写「LOOP」，指代设备时写「这台设备」 |
| 来源 / 数据源（做借口时） | 「暂时读不到」「还没有开放」；作为出处标注时保留（见 §3） |
| 尚未接入 / 尚未交付 / 尚未组装 / 依赖尚未配齐 | 「还没有开放」「暂时不可用，稍后再试」 |
| 证据 | 「材料」（审核件）／「验证」（真机验证）／省略 |
| 契约 / 约定 | 「规则」，或直接省略 |
| 槽位 | 省略，或「位置」「配置」 |
| 快照 | 「结算」「结算记录」；Launch 资格快照是产品名词，保留 |
| 裁决 / 由服务端判定 | 省略（结果本来就以提交后的状态为准） |
| 本步 / 本页 | 「现在」「这里」「这一页」 |
| 预执行 / eth_call / payload / intent / registry / allowance | 「试算」「交易内容」「这笔操作」「已登记」「授权额度」 |
| 归一化 / 幂等 / 游标 / 索引 | 省略；说用户能看见的后果 |
| RPC 端点 / chainId | 「链上节点」「BNB Smart Chain」 |

英文缩写只在它是产品名或行业通用名时保留：LOOP、Launch、DApp、BNB Smart Chain、
GoPlus、Privy、Stream、ERC-20、USD1、Passkey、KYB、Tier、Mining Power。

## 2. 替换原则

1. **一句话说清「现在不能做什么」。** 需要时再加**一句**「什么时候／怎样能做」。
   两句为上限。
2. **不承诺。** 可以写「开放后会在这里显示审核状态」，不能写「我们会尽快上线」
   或给出日期。
3. **不解释实现。** 用户不需要知道是模块没组装、索引没追上还是密钥没配置；
   他需要知道这一页现在能不能用。
4. **不推断。** 读不到 ≠ 为零、≠ 安全、≠ 没有记录。原型的这条语气保留：
   「这里是暂时读不到，不是没有记录。」
5. **同一屏不重复。** `message` 和 `reason` 不能是同一句话的两种说法；
   `message` 说事实，`reason` 说时机或影响。
6. **技术细节下沉。** 规则版本、观察时间、出处、区块高度只出现在
   `LoopDisclosure`／「详情」折叠区，或时间戳小字里，不进主文案。

## 3. 保留项

这些不是内部词，是产品承诺的一部分，继续写：

- 出处与时间标注：`来源 DexScreener · 观察于 3 分钟前`、`区块高度 4213xxxx`、
  `规则版本 … · 生效于 …`。它们属于 §2.6 的小字，不进主句。
- 「演示数据」「开发预览」标注。
- 「BSC 测试网」徽标与它的一次性说明。

## 4. 常用句式表

| 场景 | 句式 | 例子 |
| --- | --- | --- |
| 功能未开放 | `{对象}还没有开放。` | 兑换还没有开放，这一页没有买卖入口。 |
| 临时不可用 | `{对象}暂时不可用，稍后再试。` | 行情暂时不可用，稍后再试。 |
| 读不到数据 | `{对象}暂时读不到。` | 在线人数暂时读不到。 |
| 读不到 + 后果 | `{对象}暂时读不到，这里不显示{数字/内容}。` | 资产数据暂时读不到，这里不显示数字。 |
| 空结果 | `{范围}下没有{对象}。` | 这个排序下没有社区。 |
| 无权限 | `当前账号没有执行这个操作的权限。` | —— |
| 地区限制 | `你所在的地区暂时不支持这个操作，没有发生任何变化。` | —— |
| 离线 | `设备已离线，这一页没有读到数据，也没有提交任何操作。` | —— |
| 需要前置动作 | `需要先{动作}，才能{目标}。` | 需要先加入该社区，才能进入官方群。 |
| 操作失败且未提交 | `{原因}，没有提交任何交易。` | 价格影响超过 5%，已阻止这笔兑换。 |
| 结果未知 | `{事实}，结果未确认。请查看最新状态后再决定是否重试。` | —— |
| 开放后的行为 | `开放后{可见结果}。` | 开放后会在这里显示审核状态。 |
| 澄清歧义 | `{事实}。这不代表{错误推论}。` | 这不代表它安全。 |
