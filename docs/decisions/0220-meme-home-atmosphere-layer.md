# 0220 · MEME 主页氛围层（S262 设计稿 A + 预告空态 + 镀铬默认头像 + 滴漆进度条），用户 10-21 裁决（S264-mobile）

## Status

Accepted 2026-10-21。基线 `integration/v2` 8827826f。依据：用户 2026-10-21 裁决选 S262 设计稿 **A 氛围版**，并加三样：
长图里「预告」空态（皇冠线稿 + 一句话 + 「我要发射」）、B 版镀铬默认头像、长图里进度条末端滴漆。
只改 App 的 MEME Tab 主页（发射台列表页）与底部 Tab 栏选中态；不新增依赖、字体，`pubspec.lock` 不变；route manifest 不变；不改 loop-api。

## Context

设计稿是规格：`a.html`（一屏）、`a-long.html`（完整滚动）、`b.html`（只取镀铬头像），尺寸 / 颜色 / 透明度 / 位置按 CSS 搬。
素材是从需求方 looplabs.meme 海报与 hero 裁切 / 抠图 / 程序生成的临时件，见 `assets/brand/atmo-SOURCES.md`。

## Decision

1. **素材**：12 件拷入 `assets/brand/atmo-*`（`LoopAtmoAssets`），镀铬手转 webp（774 px，q85，带 alpha，137 KB），其余长边 ≤ 800；
   主页与 Tab 栏 `precacheImage` 预解码。上线前要需求方分层源文件替换。
2. **背景墙**：`LoopDashboardPage.backdrop`（新可选参数，默认 null 不影响其他页）在 MEME 主页下垫一层不滚动的墙：
   墙纹理 85 % 叠 Ink、纵向 Ink 15 % → 70 % 压暗、左上紫雾 15 %、右下黄雾 11 %。有 backdrop 时吸顶栏画同一层墙（裁到栏自身大小），看上去与页面同底，滚动内容从其下方经过不透出。
3. **顶栏**：标题「MEME」后方露出墙皇冠（60 %，−8°，left 52 / top −14 / 宽 84），被标题盖住。
4. **Banner（活动卡）**：220 高、16 圆角；底层 = 活动封面（无封面则墙纹理 90 %）+ 紫雾 55 % + 黄雾 12 % + 左→右 Ink 渐隐；
   左侧标题 26/700 Chalk + 紫笔刷、说明（≤ 2 行）13、日期行 12、黄实心「去参与」40 高；右侧镀铬手 171×170 越出卡片右 14 / 下 16，
   手上黄皇冠（−14°），右上「IN THE LOOP」tag（−5°）。镀铬手每 6 s 一次高光扫过（ShaderMask），系统减少动效时不跑。
   翻页点：当前 16×6 紫胶囊，其余 6×6 Chalk 28 %，落在卡片下方 12 px。事件页（发射主事件）保留 232 高。
5. **实时成交 → 紫色跑马灯**：banner 下 36 高紫带（44 高点击行内）；数据 = overview 最近 10 条；一行匀速 24 px/s 循环，左端「● 实时」墨色胶囊、
   右端「全部 ›」带紫色渐隐；买入 / 卖出放墨色小底。无成交显示「暂无成交」不滚、无「全部」。「全部」打开底部弹层列出这 10 条（原展开列表，行可点进项目 / 头像进主页）。
   原三行「实时」卡片删除。减少动效时不滚。
6. **阶段胶囊**：36 高（44 点击），选中紫实心白字 + 左上小黄喷点（−18°）。无主事件时选中第一个有项目的阶段。
7. **区块**：「01 内盘 / 02 预告 / 03 已毕业 …」：Anton 30 黄编号 + 右上小喷溅（75 %，12°），中文 16/700；编号按页面上实际出现的分组顺序。
   「全部 ›」只在有去处时画（已毕业且调用方给了 `onOpenGraduated`）；生产 MEME Tab 没有已毕业独立列表（决策 0217），因此目前不画。
8. **项目板**：每组一块 card 底 16 圆角板，行高 72、行间 1 px Line；头像 44 圆：有 logo 用 logo，**没有 logo 一律镀铬圆牌**（替换字母占位）；
   名称 15/600 + 代码 12 Text3；内盘 / 已毕业画 96×6 黄进度条，**进度 > 0 时末端叠滴漆**；其他阶段画倒计时 / 已铸 / 状态一行；
   右侧阶段胶囊：交易中 / 铸造中黄字 yellowSoft 底，已毕业 `#C9A0FF` 字紫 18 % 底，其余灰。
9. **预告空态**：预告计数为 0 时，「预告」区块为灰阶皇冠（去色 45 %）+「还没有排队中的项目，第一个发射的就是你」+ 黄按钮「我要发射」
   → `Launch2CreatorRoute.createPath`（创建入口不可见时不画按钮）。
10. **底部 Tab 栏**（全局）：顶边 1 px 镀铬渐变线（`LoopColors.chrome1/2/3`）；选中 Tab 图标改 Ink、背后一团黄喷雾（58 宽、−10°、80 %），文字黄；未选 Text3。
11. **主题**：`LoopColors.chrome1/2/3`、`purpleInk #C9A0FF`、`purpleCapsule`（紫 18 %）；`LoopType.sectionIndex`（Anton 30）、`LoopType.tickerFigure`（14/700）。
12. **循环动效开关**：`launch2AmbientMotionProvider`（默认开）；系统减少动效永远优先。测试 harness 默认关，使 `pumpAndSettle` 能结束。

## Consequences

- 截图：`docs/integration/S264/shots/`（模拟器 profile 包，staging 数据）。
- 测试：`test/s264_meme_home_atmosphere_test.dart` 新增（墙不随滚动、编号区块、镀铬默认头像 / 有 logo 用 logo、滴漆 > 0 有 / 0 无、预告空态与「我要发射」、喷点）；
  s182（跑马灯、弹层全部列表、动效 / 减少动效、区块标题）、s184（banner 新版式与越界）、loop_shell（镀铬线、选中喷雾）按新结构更新；
  `loop_ground_probe` 豁免两处只为压暗图片的 Ink 渐变（测试里图片不解码，落在纯 Ink 上）。
- 对比度：列表文字都在不透明 card 板上；区块标题 / 胶囊文字在压暗后的墙上（墙 85 % × Ink 压暗），真机走查确认 ≥ 4.5:1。
- 偏离设计稿：内盘「全部 ›」无去处不画（见第 7 条）；跑马灯「● 实时」绿点不做呼吸动画；Tab 喷雾用设计稿里的 `spray-yellow`（a.html 原样）而非 `splat-yellow`。
- 素材为裁切件，上线前替换为需求方源文件。
