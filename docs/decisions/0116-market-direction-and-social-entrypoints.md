# 0116 — 行情方向色与社交入口

## Status

2026-10-03，用户确认。

## Context

用户要求行情使用熟悉的涨跌配色，并在现有 LOOP 社交逻辑上补齐资料、二维码和消息操作入口。后端以多人协作的 integration/v2 分支为准。

## Decision

行情方向不受品牌三色限制：上涨 #2EBD85，下跌 #F6465D，平盘/未知保持中性。涨跌数字、K 线、成交量、趋势线和买卖方向统一使用语义 token；品牌按钮仍用 Lime。白底文字保留对比度处理，正负号同时表达方向。

社交参考 DeBox 的入口层级，复用 LOOP 的好友申请、公开资料、拉黑、群组、社区和 Stream 消息能力。允许为用户公开 ID 和社区详情生成本地二维码；不在海报中加入私聊 CID、钱包地址或未经授权的身份。持仓、交易与买入广播须来自授权的真实数据；未交付适配器不宣称可用。相机识别与删除好友等外部能力的实际接入情况单列验收。


## Consequences

复用已存在的好友申请、私聊和拉黑接口。删除好友、群消息公开身份映射、公开持仓交易与买入广播仍需后端扩展；相机识别尚无生产适配器。海报二维码只来自与当前 CID 匹配的社区上下文，不从消息作者或 URL 猜测身份。

路由核验：群资料和搜索仍保留原 PreviewConversationIdentity 与 ChatPreviewRouteGuard；转发路由仅新增初选消息 ID 和内存中的社区分享上下文，权限仍由频道成员资格检查决定。同步该受审片段的指纹，保留预览隔离回归测试。
