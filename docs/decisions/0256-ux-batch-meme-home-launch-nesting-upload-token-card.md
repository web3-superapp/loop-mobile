## UX-004 MEME 首页

1. 实时成交条去掉紫色满底：改为卡片底色 `card` + 1px `line` 描边，收进页面左右边距，圆角 12。
2. 「实时」改为紫色点 + 浅紫字、浅紫底胶囊；「买入」为绿字浅绿底、「卖出」为红字浅红底，二者不再同色。
3. 金额与单位 USD1 间距 6 → 2，基线对齐。
4. 「全部」去掉文字，只留箭头（语义标签仍为「全部实时成交」，44 触控不变）。
5. 成交条本来没有序号；带「01 / 02 / 03」的是 内盘 / 预告 / 已毕业 三个 tab（S279 加的 Anton 序号），已去掉；数量改为 12 号细字、浅色，与 tab 文字分开（MEME 页最小字号 12 的既有规则保留）。
6. 「公开内盘」等阶段标签：12 号字、20 高小胶囊（原 14 号 / 24 高），右边缘与上方价格右对齐。
7. 底部导航栏：底色 92% → 72% 并加背景模糊（sigma 20）；顶部 chrome 高光减弱到约三分之一；四周加 1px 浅色描边（前景绘制，不改格子尺寸）；下方加柔和投影，突出悬浮。
8. 顶部 banner 高度 220 → 180；文字顶距 24 → 16，标题间距收紧，倒计时 / 「去参与」底距 20 → 14。
9. 战绩四格每格加一行次要数据（均取自同一次 overview 读数，不新增接口）：本周毕业 · 累计 N；累计回购 · 截至 HH:mm（无观察时间则不显示）；勋章已铸 · 铸造中 N 个项目；进行中 · 提前购 N · 内盘 N。数据来源入口收为「战绩」标题右侧的小「(i) 来源」，有战绩时底部不再另放来源行；无战绩时保留原来的底部来源行。

## UX-005 发射套娃

根因：MEME 首页「发射」→ 发起页；发起页顶栏「我的项目」→ 我的项目页；我的项目页顶栏「＋（发起 v2 发射）」和空态按钮「发起 v2 发射」又 push 发起页，于是 发起 → 我的项目 → 发起 → … 可无限叠加，返回要退多层。

处置：
- 我的项目页去掉顶栏「＋」和空态「发起 v2 发射」按钮，发射流内部不再有发射入口；唯一入口是 MEME 首页顶部「发射」（预告空态的「我要发射」在首页本身，保留）。
- 导航层去重：新增 `launch2PushOnce`（`launch2_creator_routes.dart`），发起页的「我的项目」、我的项目页的行、项目页的跳转都走它：目标页已在栈顶则不动；已在栈下方则 pop 回那一页；否则 push。

## UX-006 上传图片页（发起 v2 发射第 1 步）

- 分组标题左对齐：「图片资料」「基础信息」。
- 头像（96 方块）、NFT 图（128 方块）都是「上传」占位方块，点方块即上传；上传后显示图片，底部小字「换一张」，上传中显示「上传中…」。去掉旁边独立的「上传头像 / 上传 NFT 图」按钮。
- 字段标题在输入框上方左对齐，字数计数放标题行右侧（`0/20`、`0/2000`，原「字」后缀去掉）；占位文字按设计图：输入项目名称 / 输入代币代码 / 介绍一下你的项目。
- 间距：组间 24、两张图之间 20、组内 12。
- 步骤条改为页面顶部满宽三段等宽进度条（`Launch2CreateStepBar`，在标题栏之上），标题下的小圆点步骤去掉。第 2 步链接字段同样改为标题在上。
- 提示文字只保留三句：「方形图片，上传前可裁剪」「将作为项目 NFT 图片显示在钱包里」（原句缩短为设计图用词，项目页同一常量同步）「名称和代币代码各 1–20 个字…」。
- `profile/presentation/avatar_editor.dart` 是居中圆头像 + 下方按钮，结构不同，且调用方在 account / profile_v2（S324 / S327 范围），本批未改。

## UX-014 聊天代币卡

共享的 `LoopTokenCard` 在 `lib/widgets/`（本批不改），聊天卡改由 feature 内的 `ChatTokenCardView`（`chat/token_card/chat_token_card_view.dart`）绘制，读同一个 `LoopTokenCardModel`，保留原有 key：
