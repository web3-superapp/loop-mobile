# 0257 · UX 问题表第二批：邀请卡、社区发现、钱包资产卡、收发兑换、个人中心

## Status

Accepted · 2026-10-31（S327-mobile）。

## Context

需求方 UX 设计师 2026-10-31 交来 18 条问题表（存档 `docs/evidence/ux-2026-10-31/`，主代理处置见 `docs/51-UX问题跟踪处置-2026-10-31.md`）。本批处理页面五条：UX-012（图 39）、UX-013（图 40）、UX-015（图 42）、UX-016（图 43–46）、UX-017（图 47）。全局按钮、输入框、空态、toast 与 ⓘ 入口由 S324 / S325 改，本批只用现有组件，不改 `lib/widgets/*`、`lib/core/theme/*`，不改接口与 codec。

## Decision

### UX-012 算力榜 · 邀请中心

- 邀请码、邀请链接、分享与海报归总成一张卡（情报 · 邀请中心与 `referral` 页共用 `_InviteCardBody`）：邀请码一行 + 右侧小复制图标；分隔线；邀请链接一行（中间省略）+ 右侧小复制图标；底部「分享邀请链接」主按钮 +「生成海报」次按钮（`LoopButton` 次级样式，S325 统一变灰）。不再有独立的「复制邀请码」按钮。没有邀请链接时只留「生成海报」，并显示原有的未开放句。
- 复制反馈：除 toast 外，被点的复制图标变成对勾（黄色），`referralCopiedHold` = 3 秒后复原；定时器在组件销毁时取消（`ReferralCopyGlyph`）。
- `referral` 页的 hero 改为这张卡，五级深度条仍在卡下方同一复合卡里。
- 推广榜（邀请中心 tab）的「我的实时排名」铭牌改为四行对齐：标题「我的实时排名」→ 名次（「第 N 名」大字，或「暂未上榜」灰色 chip）+ 右侧 TOP x% → 一句说明 →「榜单实时更新」黄点状态行。社区榜、用户榜的铭牌不变。

### UX-013 广场 · 社区发现

- 页头「发现社区」+ 右侧文字链「规则与入驻 ›」，仍打开原弹层（排序规则 + 申请入驻，内容不变）。原「按成员数 / 算力 / 讨论量 / 新建排序…」规则行移除。
- 搜索入口保留；「全部 / 我加入的」改为整行双分段主 tab（选中为紫色实心），固定吸顶。
- 新增「热门社区」模块：标题 +「查看更多 ›」（打开已有路由 `/community/discover`）+ 一张横幅卡（头像、名称、运营标签、一句简介、成员数与 7 天讨论数〔行里带了才显示〕、右侧加入按钮）。数据取当前已读列表中成员数最多的一个，不新增接口；列表少于 3 行或在「我加入的」下不显示（否则只会重复下面那一行）。
- 「全部社区」（我加入的 tab 下为「我加入的社区」）模块标题 + 右侧排序下拉「成员最多 ∨」，点开为四种排序（接口本来支持四种）的底部弹层；原四个排序 chip 去掉。
- 列表每行增加一句简介（有才显示），右侧加入按钮不变。
- **分类 chip（全部 / 算力 / Meme / DeFi / 新手）未做**：社区目录接口与 `CommunitySummary` 没有分类字段，做出来只能是假筛选。已记为待需求方确认是否新增社区分类字段（需后端加字段 + 后台维护）。因此本页没有剩余的「小 tab」，「小 tab 用黄色 chip」的规则在本页没有落点。
- 主 tab 文案保留「全部 / 我加入的」，没有改成图里的「推荐」：排序规则明确写着「热门不等于推荐」，目录不是推荐结果。

### UX-015 钱包主页资产卡

- 阅读顺序：总资产（大字 + 眼睛）→ ≈¥ → 钱包地址（带复制）→ 分隔线 → 今日盈亏（文字 + 金额，右侧 ›）→ 净值图表 → 时间范围。
- 图表始终展示，去掉「净值走势 ∨ / 收起」折叠与右侧 88×44 迷你走势；图表高度 200 → 150；`walletNetWorthExpandedProvider` 删除。
- 时间范围改为小型分段控件（`WalletSegmentedControl`：浅色轨道、选中格微抬、无紫色大胶囊），1 天 / 7 天 / 30 天 / 180 天 / 360 天。
- 今日盈亏 › 把图表切到「1 天」。
- 总资产旁的 ⓘ 调用未动（S325 统一处理）；「IN THE LOOP ALWAYS」铭牌底纹保留。

### UX-016 接收 / 发送 / 兑换

- 接收：链名不再用紫色主 tab，改为「链 icon + BNB Smart Chain」浅灰底 chip（`ReceiveNetworkChip`）；只有一条网络时不可点，多条时可切换。二维码卡、地址、复制 / 分享不变。
- 发送：步骤改为页顶等宽分段进度条（`SendStepBar`，与登录步骤条同形：已到步黄色，其余 Line2）；收款地址、发送数量的输入框去掉外层 `LoopSurfaceCard`，字段标题「收款地址」「发送数量（符号）」放在输入框上方。
- 兑换：「兑换还在验证中…」改为共用告警卡（`LoopNotice` warn），S324 会统一它的外观；支付与获得合为一张卡，中间分隔线上精确居中放 ⇅；「选择资产 ›」按钮带右箭头（`SwapAssetPickButton`）；滑点上限改为左标题 + 右侧小型分段控件（0.5% / 1% / 3%）。「滑点上限」旁 ⓘ 留给 S325。

### UX-017 个人中心

- 设置齿轮收到顶栏右侧（`LoopDashboardPage.actions`），删除整行「点一下隐藏余额」大按钮。
- 头像（带编辑圆点）左，右侧名称 + LOOP ID（带复制）+ 简介或「＋ 添加个人简介」，最右「奖励」次按钮；下一行「N 已关注 | N 粉丝 … 2026 年 10 月加入」。
- 净值卡：左侧大字金额 + 小眼睛图标（44 触控，仅本次运行时仍显示「仅本次」），右侧小型分段「24 小时 / 7 天 / 30 天 / 全部」（本页没有净值历史，仍是关闭态，点按提示原因，弱化为灰字）；下方点阵图表区与「暂无持仓」/「净值走势暂时读不到」。「净值 · 不是可用余额」为既有文案，保留；未新增说明文案。

## Consequences

- 新组件只在 feature 内：`features/wallet/wallet_segmented_control.dart`（钱包卡、兑换滑点、个人中心共用）。未改 `lib/widgets/*`、`lib/core/theme/*`，未改接口与 codec。
- 旧测试按新结构更新（s7 / s113 / s190 / s239 / s293 邀请；s111 社区；s199 钱包卡；s123e / s123g / s77a 发送与兑换；s121e / s187 个人中心），新增 `test/s327_ux_batch_test.dart`。
- 待需求方确认：社区分类字段（UX-013 分类 chip）；「推荐」tab 命名。
