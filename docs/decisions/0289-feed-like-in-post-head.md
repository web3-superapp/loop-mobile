# 0289 · 广场 · 动态：点赞移到帖头右端（S365-mobile）

## Status

Accepted · 2026-11-05（S365-mobile）。需求方验收九条第 3 条（docs/62）。改 0274 / 0278 里「♡ 在帖子底部右端单独一行」的做法。

## Context

- 需求方在 TF 66 上看广场 · 动态：「点赞放上面，别单独一行」。原来心形 + 数字在帖子最底下单独占一行（32 高，上 4 下 4），帖子显得松。

## Decision

- 心形 + 数字移到帖头那一行的右端：与作者名 / 「观点」「置顶」「毕业」等标签同一行，右对齐，竖直方向居中于作者名那一行（不是居中于头像）；底部那一行与其上下间距去掉，帖子正文 / 代币卡下面留 12 再到分隔线（与上方 12 对称，docs/58 §5.7「12 above and below」）。
- 作者区改为 `Expanded` + 靠左 `Align(heightFactor: 1)`，点赞固定在右边；作者名过长时名字先省略（原有 Flexible 规则），标签与点赞都不被挤走。
- 触控区改为 44 × 44（原 32），视觉不变：心形 22、数字 14 / 500、未赞灰色 / 已赞黄色、点击态不变。数字右缘与帖子右缘（页边距）对齐，触控区整个落在卡片内（原来靠 Transform 往页边距平移 8，平移出去的那段点不到，现改为只留左侧 8 内边距，不再平移）。
- 44 高的触控区居中于名字行时会高出头像顶 7：帖子顶部留白从 12 让出 7（变 5），作者区再下移 7，头像位置与原来一致，触控区完整在帖头行内、可点。
- 展开 / 收起与代币卡位置不变；键 `square-post-like` / `square-post-like-count` 保留。

## Consequences

- 帖子总高度比原来少约 24（底部 4 + 32 + 4 改为 12）。
- 文案无新增（不改 ARB）。
- 测试：新增 `test/s365_feed_like_head_test.dart`（点赞中心与名字行中心对齐、在年龄行之上、44 × 44 且四角都能点、数字右缘贴页边距、已赞黄色；带代币卡时卡下 12 即分隔线、头像距帖顶 12；320 宽长作者名省略且标签与点赞都在、0 赞显示「0」；官方帖头也带点赞）。旧测试 s353a / s187_4 / s268 / s350a 的点赞断言（右缘贴页边距、点击切换）在新布局下仍成立，未改。
