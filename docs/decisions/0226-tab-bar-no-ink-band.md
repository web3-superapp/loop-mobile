# 0226 · Tab 栏后面不再是一条黑底（S265e-mobile）

## Status

Accepted 2026-10-21。基线 `integration/v2` 792b1da4（S265d 合入后）。依据：用户看安卓 build 39 的广场页，原话「后边的黑色背景拿掉」，并圈出了浮动 Tab 栏所在的整个底部区域：栏左右两侧，以及栏下方到屏幕底的安全区。
不新增依赖，`pubspec.lock` 不变；route manifest 不变；不改 loop-api；不碰交易面板文件（S266 在改）。

## Context

先在测试里逐层检查了这块区域实际画了什么：
- 壳本来就用了 `Scaffold(extendBody: true)`，页面内容一直铺在 Tab 栏后面。
- 广场 / 聊天 / 情报 / 钱包的墙背景层下沿正好在屏幕底（844），中间没有任何不透明层盖在墙上面；唯一的 Ink 是壳和页面自己的 Scaffold 底色，都在墙下面。

所以截图里那条黑底不是某个多余的 Ink 色块，而是两件事叠在一起：
1. **墙自己的压暗层**（0220 第 2 条）从上到下 Ink 15 % → 45 % → **70 %**。墙纹理本身就很暗（实测亮度均值 9、p99 27，满分 255），到页面最底部再压 70 %，看上去就是纯黑。浮动 Tab 栏正好在这一段，四周就是一圈「黑底」。
2. **安卓系统导航栏的半透明遮罩**。targetSdk 36 在安卓 15+ 上强制全屏绘制，三键导航时系统会在导航栏区域加一层对比遮罩（`isNavigationBarContrastEnforced` 默认为 true），把栏下方的安全区再盖一层深色。App 之前从没设置过系统栏样式。

## Decision

1. **墙的压暗层不再继续往下加深**：`LoopWallBackdrop` 改为 Ink 15 % → 45 %（页面 55 % 处）→ **45 %**（原来是 70 %）。页面下半部、Tab 栏后面就是墙本身。五个 Tab 共用这个组件，一起生效。
2. **系统导航栏透明、不加遮罩**：五个 Tab 的壳外包一层系统栏样式 `loopTabSystemOverlay`：导航栏颜色与分隔线透明，`systemNavigationBarContrastEnforced: false`，图标为浅色；状态栏同样透明、浅色图标。
3. **Tab 栏本体**：保留 card 底、20 圆角、顶边镀铬线、选中黄喷雾，底色改为 card 92 %（`loopTabBarGround = #111114 @ 0xEB`），让墙隐约透一点，不做模糊。栏下方安全区本来就没有任何底色，保持透明。
4. **列表底部留白**：不需要一页一页加。`extendBody` 会把 Tab 栏高 + 安全区算进页面拿到的底部内边距（`MediaQuery.paddingOf(context).bottom`），五个 Tab 页的骨架（`tabPage: true`）一直用这个量做列表底部留白，聊天列表另加「发起」键的高度（`chatInboxListBottomPadding`）。`LoopTabBarScope` 只用来判断「当前是否在壳里」，不提供高度，所以没有改成走它。
5. **没有墙的页面不变**：如 launch2 未开时的 MEME 页仍是纯 Ink 页面，底部内边距不变。

## Consequences

- **测试**：新增 `test/s265e_tab_bar_no_ink_band_test.dart`，4 条：
  - 聊天 / 广场 / 情报 / 钱包：墙铺满屏幕（下沿 = 844）；Tab 栏下方安全区、栏左侧都没有任何不透明层盖在墙上（统计时排除墙下面的层、墙自身和吸顶栏里的墙切片）；页面拿到的底部内边距 ≥ Tab 栏高 + 安全区。
  - 墙的压暗层最深 45 %，底部也是 45 %。
  - Tab 栏底色为 card 92 %；系统导航栏透明、不加遮罩。
  - 没有墙的 MEME 页仍无墙，底部内边距 = Tab 栏高 + 安全区。
- **对比度**：墙 p99 像素在页面底部合成后约为 `#111111`（原来约 `#0E0E0E`），列表文字都在 card 或聊天半透明板上，不受影响。
- **局限**：
  - 测试只能证明 App 自己没有在墙上再画不透明层，系统导航栏遮罩是否消失必须真机确认，三键导航和手势导航各看一次。
  - 安卓 14 及以下不会强制全屏绘制，导航栏仍由系统绘制。本单没有在 `main.dart` 里改成全局全屏绘制：那会影响所有二级页的底部留白，留给另一单。
